# AdBuddy — AI-Powered Ad Campaign Discovery Tool

## Overview
AdBuddy is a Streamlit web app that helps marketing scholars discover and analyze 700+ real advertising campaigns using hybrid search (BM25 + semantic), multi-dimensional filters, and an AI-powered chatbot.

## Live Demo
[https://ai-engineering-fh-zkn-project-mkt-finder.streamlit.app/](https://ai-engineering-fh-zkn-project-mkt-finder.streamlit.app/)

## Setup (Run Locally)

1. Clone the repo
2. Install dependencies (shown in requirements.txt)
3. Insert API keys to placeholders in secrets.toml.example
4. Run app.py
